Happy New Year to the RPTools Community. The MapTool elves did not take much of a break over the holidays and have produced MapTool 1.5.9. This release focused on clearing out bugs, both old and new, and bringing our software dependencies up to date. The release highlights are:
- Improvement to memory usage for campaigns with a large number of maps
- Multiple bug fixes
- More translation updates
- Multiple 3rd party libraries brought up their current version
- 20+ new or improved wiki pages by Melek and other volunteers
- This will be the last release that will install to Windows 98 or Vista. Going forward will require Windows 7 or higher for our Microsoft users

Check out the [Changelog](https://github.com/RPTools/maptool/blob/1.5.9/CHANGE_LOG.md) for a full list of changes.

Excited about the new functionality? Let’s discuss in the comments below or on one of our many social outlets.

You can download available versions of MapTool from [GitHub](https://github.com/RPTools/maptool/releases/latest).

All users running versions prior to 1.8.3 are strongly encouraged to update. See [this announcement post]({{ site.data.links.forums | escape }}/viewtopic.php?f=1&t=29314)
on our forum.

A JAR file version may be downloaded as well but is only recommended for developers or other advanced users.

Mac Users are encouraged to use the PKG version of the install. Windows users are encouraged to use the MSI.

use the tool. Our *Community* page has more links; see the toolbar at the top of the page.
