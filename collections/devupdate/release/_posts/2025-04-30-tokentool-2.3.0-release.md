A new version of TokenTool has been released with improved localization and performance.

## Highlights

- Add Chinese Simplified localization ([#441][pr-441])
- Update to Java 21 ([#452][pr-452])
- Improve image preview performance on Linux ([#453][pr-453])

You can download the new version of TokenTool from [the toolbox][tokentool-toolbox].

A JAR file version may be downloaded as well but is only recommended for developers or other advanced users.

Mac Users are encouraged to use the PKG version of the install. Windows users are encouraged to use the MSI.

If you need help, please join our [Discord Server][discord]. A list of all changes can be found in our
[Change Log][changelog].
