The RPTools are free for use. Any use.

Our only request is that you use and enjoy the tools, and we encourage you to be a participant in the community. We love feedback and bug reports so that we can
make the tools better. In fact, the tools are community driven, so “no feedback, no development.”

The best way to provide feedback is via the [forums]({{ site.data.links.forums | escape }}) or the
[MapTool discord server]({{ site.data.links.discord | escape }}). If you wish to donate, you can download the tools from DriveThruRPG using the “Pay What You
Want Feature.” All donations go to pay for server hosting and other fees asscosiated with an Open Source project.

Do you enjoy RPTools software and want to have a voice our community? Please join and support one of our many social outlets.
