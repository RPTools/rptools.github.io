Stabilized Tools

Warning

These tools are no longer under active development and no longer receive support. Some of their functionality has been moved into one of the active tools.

Each tool requires you to have a correctly configured Java installation. If you have Java configured correctly, you should be able to double click on the downloaded JAR file to run each of the tools. However, depending on your Java install, you may need to invoke the command line for your operating system to run the program.
